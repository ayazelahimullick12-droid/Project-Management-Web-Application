## Current process (as-is) {#current_process}

The field officer writes each collection in the group register and copies the totals into the branch system the next day.

## Future process (to-be) {#future_process}

The field officer records each collection on the tablet during the meeting. The tablet syncs when a connection is available and the branch manager sees the totals the same evening.

## Business requirements {#requirements}

- **BR-01:** Record collections offline at the meeting. *(OBJ-1)*
- **BR-02:** Sync automatically when a connection returns. *(OBJ-1)*
- **BR-03:** Branch managers see daily totals per officer. *(OBJ-2)*

## Reporting needs {#reports}

Daily collection totals per officer; weekly overdue list per group.
